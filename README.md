# 学生女孩重度依赖 · 可玩原型 v0.4

## 运行

直接打开 `dist/index.html` 即可游玩。无需安装依赖。浏览器若限制本地文件存档，使用普通静态服务器打开dist目录，例如 `python -m http.server 8765 --directory dist`，再访问 http://127.0.0.1:8765 。

游戏可自动保存当前局，结局相册会保留已经解锁的结局。全部数据只保存在当前浏览器，本地版与托管版的存档互不共享。代码无外部字体、脚本、分析或账号依赖。

## 已实现

- 14天、每天3行动、最多42回合；三项可见属性及已确认基础数值。
- 四科自主选科学习，学习点完全不在玩家界面展示；属性效率惩罚与期末概率判定。
- 特殊事件公式、魔法条件二分支、13种结局及完整排序。
- 每个结局前的短演出；E07指定对话，E05仅虚拟电脑进入省电模式。
- 聊天、行动记录、结局相册、本地存档、重新开始、可选提示音、移动端布局。
- 原创宿舍像素立绘，复古粉紫/薄荷桌面与多窗口布局。

## 为形成可玩原型采用的暂定解释

这些是实现假设，不改变规则文档中的确认状态：

1. 四科学习点初始为0。四科独立抽样考试。
2. 学习效率与事件率读取行动前属性。
3. 基础属性变化与普通事件卡效果相加后判定，越过0/100视为触边。
4. 特殊事件已按用户反馈改为三阶段事件链，每条链每天最多推进一次。前两次为非终局小插曲，第三次才结局；魔法在第三阶段按公式二选一。
5. 学习命中普通事件时，从6张等权原创测试卡选择一张，修正幅度在已建议范围内。可在“原型说明”关闭。无稀有卡；四条三阶段行动链为本轮授权设计。
6. 对话和结局演出不扣回合，也不改变已经确定的结局。恋爱结局标题仍使用“恋爱结局”。

## v0.5 校园随机补丁

- 每次行动后抽取一条校园事件，共44条；与三阶段特殊结局链分开判定。默认开启，可在原型说明关闭。
- 最近5条事件不重复；行动专属事件权重1.6，通用1。亢奋≥65时负向/正向亢奋事件权重再乘2.5/0.35；亢奋≤30时乘0.18/3；其余乘1。这是首版可调平衡参数，不保证每次降温。
- 生理期事件第3天起有机会出现，每局最多一次；随后2天内可出现照顾事件，不持续自动扣血。其他事件可关联行动、日程与故事阶段。
- 行动和校园事件的属性效果合并后统一检查边界。特殊结局＞极值结局＞期末；事件结果先显示，确认后进入已判定的结局。刷新恢复同一事件，不再抽签或重复扣次数。
- 四科近况按该科学习行动次数显示：0尚未翻开，1第一章摸索，2第二章探路，3～4复习中，5～6刷题中，≥7错题回访中。标签是复习活动足迹，和学习点、及格率不对应。
- 行动属性方向直接显示，数字仍隐藏；保留临近结局提醒。兼容v1/v2存档。
- 验证：26组基础规则、6项行动路由、成绩单回归、校园事件测试及500局模拟；390px手机布局和事件刷新恢复实测。
